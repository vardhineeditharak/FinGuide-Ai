# FinGuide-Ai — AI Agent for Digital Financial Literacy

A RAG-powered assistant that answers questions about UPI, online scams, interest rates, and
budgeting, grounded in curated financial-literacy content, generated by **IBM watsonx.ai Granite**.

## Premium Features Added
- **Conversation Memory (Multi-turn Context)**: Remembers the last few turns of conversation history so users can ask natural follow-up questions (e.g., "How do I secure my UPI?" followed by "What if I get a suspicious link?").
- **Proactive Scam warning**: Scans queries for scam keywords (OTP, PIN, CVV, fake calls) and instantly displays an alert banner highlighting the National Cyber Crime Helpline (**1930**).
- **Feedback Collection**: Lets users rate answers with 👍 / 👎 buttons, saving ratings directly to a local SQLite logs database.

## Architecture

```
User query (English)
      │
      ▼
Check for Scam Keywords (Instantly triggers 1930 Helpline Banner if found)
      │
      ▼
Embed query (local MiniLM) → search SQLite vector DB → top-k chunks
      │
      ▼
Prompt = system rules + history + retrieved context + query
      │
      ▼
IBM watsonx.ai Granite model → generated answer
      │
      ▼
Flask API → chat UI with interactive feedback actions
```

## Setup

### 1. Install dependencies
```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Get your IBM credentials
Using your Edunet-provided IBM Cloud Lite account:

1. Go to https://cloud.ibm.com and log in.
2. Search the catalog for **watsonx.ai**, create a **watsonx.ai Studio** instance (Lite/free plan).
3. Inside watsonx.ai, create a new **Project**.
4. In the project: **Manage → General** → copy the **Project ID**.
5. In IBM Cloud: **Manage → Access (IAM) → API keys** → create a new key → copy it immediately (shown once).
6. Note your region endpoint (usually `https://us-south.ml.cloud.ibm.com`).

### 3. Configure environment
```bash
cp .env.example .env
```
Edit `.env` and fill in:
```
WATSONX_API_KEY=...
WATSONX_PROJECT_ID=...
WATSONX_URL=https://us-south.ml.cloud.ibm.com
GRANITE_MODEL_ID=ibm/granite-3-8b-instruct
```

### 4. Build the knowledge base & logs table
```bash
python ingest.py
python migrate_db.py
python setup_feedback_db.py
```
This reads everything in `/data`, chunks it, embeds it locally, stores it in SQLite, and initializes the feedback log table.

### 5. Run the app
```bash
python app.py
```
Visit **http://localhost:5000** — you'll see the FinGuide-Ai chat UI.

## How it behaves without credentials yet

If `WATSONX_API_KEY` / `WATSONX_PROJECT_ID` aren't set, `rag_pipeline.py` automatically falls back
to a "demo mode" response that shows the raw retrieved context instead of a Granite-generated
answer, so you can verify the retrieval pipeline works end-to-end before wiring up billing/keys.
The chat UI flags this clearly with a "⚠ Demo mode" badge.

## Extending the knowledge base

Drop more `.md` or `.txt` files into `/data` — e.g. scraped/summarized content from:
- rbi.org.in (interest rate circulars, KYC/loan guidelines)
- npci.org.in (UPI operational guidelines)
- cybercrime.gov.in (scam reporting procedures)

Then re-run `python ingest.py && python migrate_db.py`. Keep each source file focused on one topic for cleaner retrieval,
and always cite the source name in the filename (it's surfaced to users as a citation).

## Safety design choices

- The system prompt in `rag_pipeline.py` instructs Granite to answer **only from retrieved
  context**, never give investment/legal advice, and always attach a safety reminder on
  scam/OTP/PIN-related questions.
- Retrieved source filenames are shown to the user under every answer for transparency.
- If no relevant context is retrieved, the assistant says so honestly rather than guessing.

## Deploying to IBM Cloud (Lite tier)

For a live demo link:
1. Push this repo to GitHub.
2. In IBM Cloud, create a **Code Engine** project (Lite plan covers a generous free tier).
3. Create an application from your GitHub repo (Code Engine can build directly from a
   Dockerfile, or use its buildpack for Python).
4. Set the same environment variables from `.env` in Code Engine's app configuration
   (Environment variables section) instead of committing `.env`.
5. Code Engine will give you a public HTTPS URL for your demo.
